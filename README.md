# Sauna Copacabana — Propuesta de software

Propuesta de desarrollo y maqueta navegable de un sistema para sauna: recepción con manillas,
casilleros, cafetería con cargo a la manilla, comandas de cocina, reservas, salida y cobro,
inventario, caja y membresías.

- `index.html` — la propuesta.
- `mockup.html` — la maqueta del sistema (datos de ejemplo, no guarda nada).
- `css/estilos.css` — estilos compartidos (tema claro y oscuro, adaptable a celular).
- `js/mockup.js` — lógica y datos de ejemplo de la maqueta.

Página estática: se abre directo en el navegador o se publica con GitHub Pages.
